# CR7 Tribute — WebDev Level 2 · Task 2

A premium one-page tribute to Cristiano Ronaldo — cinematic hero, biography, 7-stop photo career journey , 6-stat rolling record legacy, quote band and legacy finale — in a black / cream / gold editorial style.

## Description

From Madeira's streets to global icon: title + tagline hero, 4 original biography paragraphs, 7 photo career cards with club crests , 6-stat record legacy, two distinct quote bands and iconic-moments gallery.

- HTML5 — Semantic structure
- CSS3 — Theme, Flexbox/Grid, masks, responsive + overlay nav
- JavaScript — Overlay navigation, active link, reveal
