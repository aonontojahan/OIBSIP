# MyTodo — WebDev Level 2 · Task 3

A colorful browser-based to-do list app for managing daily tasks across Pending and Completed lists.

## Description

This project is an interactive task manager with an "Organize Today, Build a Better Tomorrow" hero, an add-task bar with optional due-date picker, and two equal-height panels for pending and completed tasks. Clicking a checkbox moves a task between lists, and every task carries added/completed timestamps.

## Tech Used

- HTML5 — Page structure
- CSS3 — Styling, gradient hero, Grid panels, responsive layout
- JavaScript — Task logic, vanilla JS, localStorage persistence


## Features

- [x] Input field + "Add Task" button to create new tasks
- [x] New tasks appear immediately in the Pending Tasks list
- [x] Checkbox toggle — completed tasks move to the Completed Tasks list
- [x] Edit button for inline text + due-date editing (pending tasks)
- [x] Delete button on every task + Clear button for the completed list
- [x] Count badges: "X pending" and "Y completed" above each list
- [x] Due-date picker to schedule a task for a coming day
- [x] Timestamps on each task (added date/time, completed date/time)
- [x] Tasks persist across page refreshes using localStorage
- [x] Empty state messages when a list has no items
- [x] Equal-height cards, responsive design for mobile
