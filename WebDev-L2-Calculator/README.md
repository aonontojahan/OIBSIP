# CALCULATOR — WebDev Level 2 · Task 1

A clean, professional browser-based calculator built as part of the OIBSIP Web Development internship.

## Description

This project is a fully functional calculator that performs basic arithmetic operations through a user-friendly button interface. The input expression appears on the top display line, while the result line stays at `0` during typing and shows the answer only after pressing `=`.

The result can be copied by clicking on the result value (`Copied!` confirmation appears). 

Operator chaining is supported without requiring a full reset (e.g. `5+3×2 = 11` with correct precedence).

## Tech Used

- HTML5 — Page structure
- CSS3 — Styling and CSS Grid layout
- JavaScript — Calculator logic, vanilla JS, no eval()


## Features

- [x] Display screen showing current input
- [x] Numeric buttons `0–9` + decimal `.` button
- [x] Operators: `+`, `−`, `×`, `÷`, `%`
- [x] `=` evaluates, `C` clears, `⌫` backspace/deletes 
- [x] Division-by-zero protection 
- [x] Operator chaining with correct precedence
- [x] Click result to copy
- [x] Keyboard support
- [x] Single-viewport layout — no page scroll
- [x] Responsive design for mobile
